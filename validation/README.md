# Validation of the course-to-domain classification

This directory holds the validation reported in the paper (Section 3.2). CurricuMap's
rule-based classification is applied to the real course titles of one registrar export and
compared with an exact-title lookup and with NLP and large-language-model (LLM) alternatives
given the labelled official list, the domain definitions, or both. The validation tables and the
numbers the paper's text takes from them are produced by the scripts here and written to
`../paper/generated/` by `paper_numbers.py`.

## Question

Does a taxonomy written from the national curriculum documents assign the course titles of a
real registrar export to the domains a fixed convention prescribes, what do its rules add to a
lookup of the labelled official titles, and how do NLP and LLM classifiers given the same
information compare?

## Data

| File | Contents |
|---|---|
| `data/yok_programmes.csv` | **Authoring source.** The 158 entries (150 distinct titles) of the two national English Language Teaching programmes of the Turkish Council of Higher Education (YÖK): the 2018 programme (compulsory courses and the MB, GK and AE elective pools) and the 2006 programme (compulsory courses), each with its official category and its domain under the convention below. |
| `data/iuc_elt_catalog.csv` | **Test set.** The 143 distinct course titles in the 2017–2026 transcript export of the ELT programme at İstanbul University-Cerrahpaşa, exactly as the registrar spells them, with the registrar course codes (where the export gives one), the matching official programme entry and category, and the reference domain. No student-level data are included, and enrolment counts are withheld because some courses were taken by very few students. |
| `taxonomies/elt_yok_2018_v0.1.0.yaml` | The ELT taxonomy released with v0.1.0, for comparison. |
| `taxonomies/elt_official_titles_lookup.yaml` | Generated by `predict_rules.py`: no rules, the 158 labelled official entries as exact-title overrides. |
| `authoring/` | The instructions and the complete tool-call log of the LLM agents that wrote the v0.2.0 taxonomy (see `authoring/README.md`). |

Official categories: **MB** (Meslek Bilgisi, teaching-profession knowledge), **GK** (Genel
Kültür, general culture), **AE** (2018) / **A** (2006) (field courses). 138 test titles are
renderings of an official entry and take its category. Four of the five other titles take it
from the registrar's course-code prefix (`GKDE`, `AEIO`) or from the 2006 elective slot they
fill; one, a university-wide elective, has none.

Test titles fall into three strata, used throughout the evaluation:

- **exact** (128): identical to their official title after CurricuMap's normalisation (Turkish
  case folding and whitespace);
- **variant** (10): other registrar renderings of an official title (abbreviations, a missing
  colon or hyphen, a dropped circumflex, a word split in two, an Arabic numeral, a truncation,
  a language added in parentheses);
  one of them, *İNGİLİZCE ÖĞRETİMİNDE SINAV HAZIRLAMA*, is the short form that the 2018 programme
  document prints in its semester table, whose course descriptions give the full title;
- **unseen** (5): in neither national programme.

## Reference labels (domain convention)

- **R1**: an MB course → `pedagogy`
- **R2**: a GK course → `general_ed`
- **R3**: a field course goes to the domain of its subject matter. A course on, or on the
  teaching of, language skills, linguistics or literature goes to that domain; ELT
  methodology courses not tied to one of these go to `pedagogy`.
- **R4**: second-foreign-language courses (2006 "İkinci Yabancı Dil") → `general_ed`, as their
  2018 successor "Yabancı Dil" is a GK course.
- **R5**: university-wide common electives outside both programmes → `general_ed`.

R1 and R2 (79 test titles) follow from the official category, and R4 (one title) from the
category of the course's 2018 successor. R3 (62 test titles) records the authors' decisions,
which no external source checks. R5 was added when the test set was labelled, after
its one university-wide elective had been seen; the taxonomy's authors were given R1–R4 only.
The official YÖK course descriptions were used to resolve courses whose titles name a teaching
method but whose content develops the student's own English (e.g. *Kitle İletişiminde
İngilizce*). One official title is in both programmes with different categories: *Türk Eğitim
Tarihi* is MB in 2018 and GK in 2006. A title-level specification can follow only one; the
bundled taxonomy follows 2018. The test set has one registrar title for the course (code `INOG2024`), labelled by the 2018 programme, so the evaluation cannot detect the
conflict; a 2006-programme cohort needs an override (see `../KNOWN_ISSUES.md`).

## How the taxonomy was written (blinding)

The bundled taxonomy `elt_yok_2018` (v0.2.0) was drafted by an LLM coding assistant (Claude
Opus 5.5 in Claude Code) from the convention (R1–R4) and `data/yok_programmes.csv`, critiqued by
three further instances (generalisation, false positives, fidelity to the convention) and
revised by a fifth, in 85 minutes of wall-clock time. The catalogue had been moved out of the
repository. The instructions and the input of every tool call of the five agents are in
`authoring/`: none opened the catalogue, no course code appears, and replaying the log
reproduces the frozen file. The instructions were written by an assistant that had seen the
catalogue: they quote one registrar variant verbatim and name two hypothetical courses that
resemble catalogue titles, and the reviser probed a second variant verbatim
(`authoring/README.md`). Neither the variant nor the unseen titles are therefore a fully blind
test. The drafter, which saw none of these titles, had already assigned all exact and variant
titles correctly, and three of the five unseen ones. By design, no human edited the rules.

The specification was frozen (its SHA-256 is in `results/frozen_taxonomy.sha256`) and applied
once to the test titles. `results/taxonomy_authoring_record.json` holds abridged reports of the
agents: the files the drafter and the reviser listed as read, the three critiques, and how each
finding was handled; the critics' reads are in `authoring/tool_calls.jsonl`.

## Systems

| System | Information | Script |
|---|---|---|
| CurricuMap, ELT rules (v0.2.0) | written from the labelled official list | `predict_rules.py` |
| CurricuMap, official titles as overrides (no rules) | labelled official list | `predict_rules.py` |
| CurricuMap, taxonomy released with v0.1.0 | written for synthetic data | `predict_rules.py` |
| String similarity: label of the most similar official title (rapidfuzz token-set ratio; ties broken by the plain ratio, then list order) | labelled list | `predict_nlp.py` |
| Character 2–5-gram TF-IDF + logistic regression trained on the official titles (scikit-learn) | labelled list | `predict_nlp.py` |
| multilingual-e5-large: nearest official title, and zero-shot (nearest domain definition) | labelled list / definitions | `predict_nlp.py` |
| Gemma 4 12B instruction-tuned, 4-bit quantised (`mlx-community/gemma-4-12B-it-qat-4bit`), run locally with MLX: zero-shot and few-shot, greedy plus 5 sampled runs (temperature 1.0) | definitions / both | `predict_llm.py` |
| Claude Opus 5.5 via the Claude Code CLI (tools disabled, fixed system prompt, client-default sampling), 5 runs each, on 1 October 2026 | definitions / both | `predict_llm.py` |

The domain definitions in `prompts/definitions.md` were written from the national programmes
by the authors' assistant, which had seen the catalogue; they mention German as an example of a
second foreign language, university-wide common electives, and technology in ELT (one of
the five titles outside both programmes), all of which occur in it.
Few-shot prompts contain the definitions plus all 158 labelled official entries. Each LLM call
classifies all test titles at once and returns JSON. The exact prompts and every raw response
are in `results/llm_raw/`. Model revisions are pinned in the scripts.

The first version of the string-similarity baseline broke ties by list order; all five of its
errors were ties with the correct title (token-set ratio is 100 whenever one title's words are
a subset of the other's). Ties are now broken by the plain ratio.

## Metrics (`evaluate.py`)

- **Coverage**: share of titles assigned a domain. CurricuMap flags a title that matches no
  rule as `unmatched`; the other systems always answer.
- **Accuracy**: share of all 143 titles assigned the reference domain, with flagged titles
  counted as errors, and a Wilson 95% interval. The interval treats titles as independent;
  numbered courses (Dilbilimi 1 and 2) share a stem, and the 143 titles form 114 stems. For a
  system that is right on every title, treating the stems as the units lowers the bound from
  97.4% to 96.7%.
- **Correct titles per stratum** (exact, variant, unseen).
- **Paired comparison**: an exact McNemar test of each system against CurricuMap v0.2.0 on the
  same titles. Repeated LLM runs are tested run by run; the CSVs give the range.
- In the CSVs only: macro-F1, Cohen's κ, agreement with the
  official category (a title without one counts as compatible with any domain), and, for
  repeated runs, the share of titles labelled identically in every run and Fleiss' κ.

The paper's table lists the deterministic systems (greedy decoding for Gemma; Claude returned
identical labels in all five runs). The sampled Gemma runs are summarised in the text.

## Reproduce

```bash
pip install -e ..                     # CurricuMap
pip install -r requirements.txt       # baselines (MLX needs Apple silicon)
python predict_rules.py
python predict_nlp.py
python predict_llm.py gemma zeroshot 5 && python predict_llm.py gemma fewshot 5
python predict_llm.py claude zeroshot 5 && python predict_llm.py claude fewshot 5
python evaluate.py && python effort.py && python paper_numbers.py
```

The Claude runs cannot be repeated exactly: the hosted model can change, and its sampling is
not seeded. Their scores can always be recomputed from the released raw outputs.

## Limitations

The test set is one institution's catalogue (143 titles over two curricula), and 128 of its
titles are official titles in upper case, so any method given the labelled official list
recognises them. The reference for field courses reflects the authors' convention; no
independent multi-rater annotation was performed, so agreement between experts is not
measured.
